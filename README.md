# Projet-POO-jeu-de-plateforme
Mon projet de terminale et première fois que j'utilise la POO dans un projet. C'est un simple jeu de plateforme qui consiste à récupérer des clés dans des coffres pour ouvrir d'autres coffres avec des armes dedans qui permettent de tuer les monstres puis de trouver la clé qui permet de finir le niveau.
